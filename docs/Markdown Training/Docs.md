## How the Project Works

Think of the Markdown Training Project as three connected components:

### 1. Markdown

Create and format documentation using:

- Headings and paragraphs
- Numbered and bulleted lists
- Tables and hyperlinks
- Images and code blocks

### 2. Docusaurus

Use Docusaurus to:

- Organize Markdown files.
- Generate a documentation website.
- Navigate between documentation pages.
- Preview content changes locally.

### 3. Help Center

Present the documentation in an organized structure so users can easily find relevant information.

---

## Documentation Workflow

Follow this simple workflow when creating documentation:

**Create → Format → Review → Preview → Publish**

1. Create a Markdown file.
2. Add and organize the content.
3. Review the content for accuracy.
4. Preview the page in Docusaurus.
5. Publish the approved documentation.
