# Troubleshooting Guide

## Introduction

This guide provides solutions to common issues when working with the Markdown Training Project.

## Image Does Not Display

**Possible Issue 1:** The image path is incorrect.

**Solution**

1. Confirm that the image exists in the `Img` folder.
2. Check the spelling and capitalization of the filename.
3. Verify that the relative path is correct.

Use the following syntax:

```markdown
![Sample Image](../Img/Sample%20Image.png)
```

## Link Does Not Work

**Possible Issue 2:** The linked Markdown file is missing or the path is incorrect.

**Solution**

- Confirm that the target file exists.
- Verify the relative path.
- Make sure the filename and extension are correct.

## Markdown Formatting Does Not Display

**Possible Issue 2:** The Markdown syntax is incorrect or the preview has not refreshed.

**Solution**

1. Verify the Markdown syntax.
2. Save the file using `Ctrl+S`.
3. Reopen or refresh the Markdown preview.
