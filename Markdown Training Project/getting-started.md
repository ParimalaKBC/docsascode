# Getting Started

## Introduction

Welcome to the Markdown Training Project. This guide introduces the basic features and documentation structure.

## Prerequisites

Before you begin, make sure you have:

- Visual Studio Code or another Markdown editor
- Git installed on your computer
- The project folder downloaded or cloned

## Steps to Get Started

1. Open the project folder in Visual Studio Code.
2. Open `Docs/getting-started.md`.
3. Edit the Markdown content.
4. Press `Ctrl+S` to save the file.
5. Press `Ctrl+Shift+V` to preview the Markdown.
